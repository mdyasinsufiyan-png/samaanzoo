# Samaanzo storefront

## Deploy on Cloudflare Pages
1. Extract this ZIP.
2. In Cloudflare Pages, choose Create a project / Upload assets (Direct Upload).
3. Upload the extracted folder containing index.html.
4. Deploy.

This is a frontend demo. Cart data is saved in the browser's localStorage. Login, real inventory/database, order management, shipping, and payment processing are not connected yet. Product images load from Unsplash and Google Fonts is used for typography.
